#### PUNTO 4

### 1) ¿String es una tipo por valor o un tipo por referencia? 
  Es un tipo por referencia en C#
###2) ¿Qué secuencias de escape tiene el tipo string?
   Las secuencias de escape se usan para representar caracteres especiales que no se pueden escribir directamente:
  * \n Salto de linea
  * \t Tabulacion
  * \\ Imprime barra invertida
  * \" Imprime comilla doble
  * \' Imprime comilla simple
### 3) ¿Qué sucede cuando se utiliza el carácter @ y $ antes de una cadena de texto?
  El @ le dice al compilador que ignore todas las secuencias de escape dentro de la cadena.
  El $ te permite incrustar variables o expresiones de C# directamente adentro de la cadena de texto usando llaves { }.
